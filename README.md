# Target Counter Challenge

A simple mini game built from the original counter layout.

## How it works
- A random target number is chosen.
- You use the +1 and -1 buttons to move the counter.
- If the counter reaches the target before the timer ends, you win.
- Each win increases your score and streak.
- If the timer runs out, the streak resets.
- Press Reset or New Target to start a new round.

## Run it locally
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
